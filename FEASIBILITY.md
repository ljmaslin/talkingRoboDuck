# XGO conversation roadmap

Target: XGO kit + Arduino UNO Q 4GB. The kit is purchased, real hardware is pending.
It excludes audio. Candidate USB microphone/speaker parts are in the buying plan,
not claimed as a validated mobile installation.

Current checkpoint: offline speech-to-XGO movement using the actual vendor
controller, XGO policies and XGO simulated body. App Lab ZIP is the deployment
boundary; see DEPLOYMENT.md and ARCHITECTURE.md.

Still to implement/measure: real audio device access, endpointing under servo
noise, speech synthesis/playback, conversation turns and person following.
Start with stationary listening before testing capture during movement.

User has ChatGPT Plus and Google AI Plus and permits cloud AI after a budget
agreement. Current API budget is £0. No paid inference, subscription automation,
API key provisioning or credential reuse is enabled. Provider entitlements need
checking if conversation is added later. The Raspberry Pi model/RAM remains
unknown and it is not required for this simulator or UNO Q application.
